## Shared Matt Pocock skills

Use the single consolidated Matt Pocock collection installed in `~/.codex/skills`.
Invoke a skill by name and read its installed `SKILL.md` and linked resources;
do not reinstall repository copies. Resolve project files from this repository,
not from the global skill directory. Repository product policies and distinct
local wrappers remain authoritative for this project.

An unfinished skill and its parent resume on relevant replies without another
invocation. Preserve pending questions, settled decisions, current step, artifacts
and remaining completion criteria. Child completion returns to the parent's saved
step; dispatching research alone does not complete its ticket or map.
Grilling asks one question in a final response, ends the turn, and waits.
